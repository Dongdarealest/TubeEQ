# TubeEQ website (gh-pages)

This branch hosts the TubeEQ website at https://dongdarealest.github.io/TubeEQ/

## Files
- `index.html` - landing page: install guide, features, preset library, FAQ
- `presets.json` - community preset library (data-driven, rendered by JS)
- `privacy.html` - privacy policy (required for Chrome Web Store)

## Contributing a preset
1. Fork the repo
2. Add your preset to `presets.json` on this branch: name, description, author, the share `code` from TubeEQ (Share button), and the 10 `gains` values
3. Open a pull request
